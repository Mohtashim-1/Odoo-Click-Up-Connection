Odoo Click-Up Connector

Seamlessly sync your Odoo Projects and Tasks with Click-Up spaces, lists, and tasks.

Features

  • Automatic task creation on record save
  • Cron-based status sync
  • OAuth2 authentication flow

Installation

  1. Put this folder in your addons path
  2. Activate “ClickUp Connector” in Apps
  3. Configure API key under Settings → ClickUp
